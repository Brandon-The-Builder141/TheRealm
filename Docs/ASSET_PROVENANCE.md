# Asset provenance

The original Realm geometry was procedurally authored for this project. The scene now also uses the imported Kenney props described below. The project contains the Poly Haven textures listed below; the earlier claim that no downloaded textures were included was incorrect.

- FrontierEnvironment.prefab: generated by RealmArt and assembled with RealmBuilder. Emberhearth (cottages, hearth, well, cart, stores, fences, benches, notice board, lantern posts) and the ground/road/street surfaces use the original world kit authored by script in Blender (`ArtSource/World/RealmWorld.blend`), with tileable textures generated procedurally in numpy (no photographs or downloads). Forest trees (oak, fir, birch) and undergrowth (bush, fern, grass clump, log, stump) also use the original world kit, with a foliage texture generated procedurally (no photographs). Gates and seal arenas (dais, standing pillars) also use the original world kit. Borderland cliffs and modular ruins use original pass-four Blender sources under ArtSource/World/Pass4/Nature and ArtSource/World/Pass4/Ruins, reusing the existing procedural stone textures. Eleven meshes were authored without downloads.
- Materials: original HDRP material parameters and procedural textures, plus the external Poly Haven image textures listed below.
- Player character (Adventurer): original mesh, rig, procedural materials, baked textures and 15 animation clips, all authored by script in Blender (`ArtSource/Characters/RealmCharacters.blend`, build scripts stored as text blocks inside it). No scanned, downloaded or AI-generated source.
- Enemies: imported KayKit skeletons with Medium rig animations, configured through RealmEnemyVisualSet. NPCs remain original procedural prototype figures.
- Audio: runtime-generated wind, blade impact, injury and dice cues in RealmAudio. No sampled recordings.
- Font rendering uses installed Georgia and Segoe UI on Windows; font files are not copied or distributed in the project.
- Unity primitive meshes, rendering code, packages and starter HDRP scene remain subject to their existing Unity terms.

Unity's asset-generation catalog did not become available during initial implementation. No credits or paid services were purchased.

## User-imported packs (October 2026)

Kenney Survival Kit and Graveyard Kit are used for the decorative camp and graves. KayKit Skeletons and Character Animations supply animated enemies; Adventurers remains available for subsequent player integration. Each of these five packs includes its own CC0 License.txt; keep those files with the assets. Credits: Kenney (www.kenney.nl) and Kay Lousberg (www.kaylousberg.com). See `Docs/AI/ImportedAssets.md` for exact integration status.

The public repository excludes local ArtisticMechanics, Furry Squirrel, RSG_DogsPack, TerrainSampleAssets, Wolf and forrest_ground_01_4k.blend packs because their raw-source redistribution permissions have not been established. They remain installed locally and are not needed by the current Realm gameplay scene. Their presence is not a claim that they are original or CC0. Player saves, credentials, Unity caches, test captures and builds are also excluded.
